## Estructura del repositorio

- `Programa_y_Cronograma/` — programa oficial y calendario.
- `Presentaciones/` — diapositivas de cada clase en PDF.
- `Notebooks/` — cuadernos prácticos por clase, en versiones Python y R.

## Cómo abrir los notebooks en Google Colab

Para Python, abra cualquier notebook desde la carpeta correspondiente y haga clic en el badge "Open in Colab" del encabezado.

Para R, descargue el `.ipynb` correspondiente y súbalo a Colab; recuerde cambiar el runtime a R en *Entorno de ejecución → Cambiar tipo de entorno → R*.
